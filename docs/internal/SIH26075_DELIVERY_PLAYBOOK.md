# SIH26075 delivery and pitch playbook

## Thesis

PRISM Capacity Connect is not “another LMS” and not “an AI quiz generator.” It is one auditable
organizational learning loop:

`approved people → trusted trainer content → course and assessment → competency evidence → next action and trainer match → administrator insight`

Every arrow should be visible in the final demonstration.

## Two-minute demonstration

1. **Admin (0:00–0:20):** approve one synthetic Trainer and Trainee; show roles, not passwords.
2. **Trainer (0:20–0:50):** publish a resource and deadline-based questionnaire to an assigned
   cohort; show the source/review state.
3. **Trainee (0:50–1:20):** enrol, open the resource, answer the MCQ, and submit feedback.
4. **Evidence (1:20–1:40):** show the updated competency evidence and explain why the next action is
   recommended.
5. **Admin (1:40–2:00):** search for a trainer by subject, inspect the match rationale, then show the
   participation/dashboard update and homepage announcement.

If a step is not implemented, remove it from the live script and label it planned in the deck.

## Differentiators worth defending

- One competency vocabulary connects learner evidence, courses, assessments, and trainer expertise.
- AI-generated questions are source-grounded drafts with trainer approval, not automatically trusted.
- Trainer matching shows evidence and factors instead of returning an unexplained name.
- Role and object scope prevents a trainer from browsing unrelated trainees.
- Analytics come from persisted activity rather than decorative dashboard constants.
- English-first, multilingual, responsive access supports a geographically distributed workforce.

## Claims to avoid

- “Official MoES/IMD competency framework” without written validation.
- “Production-ready,” “compliant,” “government approved,” or a scale number without final evidence.
- “Three secure portals” while the hosted demo bypasses authentication.
- “Trainer library” when an upload is usable only as quiz-generation input.
- “Trainer-created questionnaire” when only AI-generated-item review exists.
- “Certification dashboard” before certificate records and workflows exist.
- Any fabricated impact percentage, user count, time saving, accuracy, or model-quality number.

## Judge questions

**Why is this more than an LMS?**

Courses, assessment evidence, competency gaps, and trainer expertise use the same versioned model;
the system can explain the next learning action and who is suited to support it.

**Is the AI trusted automatically?**

No. Uploaded material is untrusted, generated questions remain drafts, trainers review publication,
and the assistant is designed to cite authorized passages or abstain.

**Is this ready for real employee data?**

No such claim is made. The prototype uses synthetic data. A real pilot requires an approved identity
provider, hosting/data policy, content owner, threat/privacy review, and operational evidence.

**What already works?**

Answer only from the current README/evidence at the immutable demo commit. Separate reusable PRISM
foundations from SIH26075-specific workflows completed after the transition.
